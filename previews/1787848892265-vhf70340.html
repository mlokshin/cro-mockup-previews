CRO-2001 Variant: Size-availability badges are injected below the price on each product tile via client-side JS. Amber badges signal limited stock; gray badges indicate out-of-stock. This treatment aims to reduce wasted clicks on unavailable products and surface urgency for low-stock items. Note: In production, this requires size/availability data to be pre-rendered in tile data attributes or fetched via a lightweight API call.
