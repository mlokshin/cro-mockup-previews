Variant — Price Above Image
Price block repositioned above the product image using CSS order: -1 or DOM prepend scoped to @media (max-width: 768px). Injectable via tag manager. Fully reversible. No backend required.
Implementation Note
The variant is achieved by a single CSS rule injected via tag manager on PDP pages, scoped to mobile breakpoint:
@media (max-width: 768px) { .pdp-price { order: -1; } } This assumes the PDP uses a flex or grid container for its content blocks. If not, a JS DOM prepend (price node moved before image container) achieves the same result. No new data fetching, no server-side changes, no imagery changes required. Fully reversible by removing the injected rule.
